# tw-daytrading-engine

台股當沖決策輔助系統（暫定名，可調整）。目標不是預測必漲必跌，而是用盤前/開盤/盤中/尾盤的客觀數據，提高交易判斷一致性、降低衝動交易，並記錄每次決策供後續回測與優化。

跟 `daily-trading-site`（現有 AI 判斷型每日選股報告）是**不同專案**，這裡是規則引擎型的多層判斷系統（國際→大盤→族群→個股）。詳細規劃見對話留存的完整計畫文件；決策記錄與踩坑細節見 [`NOTES.md`](./NOTES.md)（不會每次自動載入，需要查細節時再讀）。

## 目前狀態：Phase 0（MVP）進行中

Phase 0 範圍：族群分類設定檔、資料擷取、VWAP／開盤高低點／昨日高低點／族群同步性計算、大盤方向引擎、「今日盤勢總覽」＋「族群雷達」兩頁網站、全自動排程（不依賴本機開機）、健檢＋LINE 通知。

不含：個股判斷、進場建議、交易日誌、回測、風控強制、模擬交易——這些是 Phase 1／2／3 才會做。

## 目錄結構

```
config/
  sectors.json       # 26 族群分類設定（代表股/領先股/跟隨股/國際對應指標），可人工調整
  thresholds.json     # （尚未建立）可調整的判斷門檻，Phase 0 後續任務會加
data/
  market-state/       # 大盤方向判斷歷史快照，依日期分檔
  sector-radar/        # 族群同步性快照，依日期分檔
  premarket/           # 盤前總覽快照，依日期分檔
  quotes/               # 最新報價快照（latest.json，不留歷史）
```

## 開發原則

- 所有判斷邏輯必須可追蹤、可解釋、可調整，不做黑箱分數。
- 缺資料要明確標示「無資料／尚未串接／資料延遲」，不可用假資料冒充正式功能。
- 每個任務都是最小可驗收單位，完成後停下來等確認，不自動接著做下一個。
